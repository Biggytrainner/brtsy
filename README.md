# ระบบยืม-คืนอุปกรณ์ทางกายภาพบำบัด (Netlify)

เว็บหน้าเดียว + ฐานข้อมูลกลางบน **Netlify Functions + Netlify Blobs** ทุกเครื่องเห็นข้อมูลชุดเดียวกัน (อัปเดตทุก 4 วินาที)
ป้องกันด้วยรหัสผ่านร่วมของหน่วยงาน

```
public/index.html            หน้าเว็บ
netlify/functions/api.mjs    API + ล็อกอิน + อ่าน/เขียนฐานข้อมูล (Blobs)
netlify/lib/logic.mjs        กติกาธุรกิจ (ตรวจเบอร์ซ้ำ สต๊อก ฯลฯ)
netlify.toml, package.json   ตั้งค่า deploy
```

## วิธี deploy

1. สร้าง repo บน GitHub แบบ **Private** แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (ต้องเห็น `netlify.toml` ที่ระดับบนสุดของ repo)
2. Netlify → **Add new site → Import an existing project** → เลือก GitHub repo นี้ (ค่า build ถูกอ่านจาก `netlify.toml` อัตโนมัติ ไม่ต้องกรอก)
3. **ก่อนกด Deploy** ไปที่ *Site configuration → Environment variables* เพิ่มค่า
   - `APP_PASSCODE` = รหัสผ่านของหน่วยงาน (**จำเป็น** ถ้าไม่ตั้ง API จะปฏิเสธทุกคำขอ แนะนำยาว 10 ตัวขึ้นไป)
   - `SESSION_SECRET` = สตริงสุ่มยาวๆ (ไม่บังคับ แต่ควรตั้ง)
4. Deploy แล้วเปิดเว็บ ใส่รหัสผ่าน ครั้งแรกระบบจะมีอุปกรณ์ 9 ชนิดตามไฟล์เดิมให้เลย (รายการยืมว่าง)

เปลี่ยนรหัสผ่านภายหลัง: แก้ `APP_PASSCODE` แล้ว Deploy ใหม่ ทุกเครื่องจะต้องล็อกอินใหม่

## ย้ายข้อมูลเก่า
เปิดเวอร์ชันเดิมบนเครื่องที่มีข้อมูลจริง → **Export JSON** → เปิดเว็บใหม่ → **Import** (รองรับไฟล์รูปแบบเดิม เพิ่ม/อัปเดตโดยไม่ลบของที่มีอยู่)

## ข้อควรระวัง
- ข้อมูลมีชื่อและ HN ผู้ป่วย: ใช้ repo Private, ห้ามเอาไฟล์ Export ขึ้น GitHub (`.gitignore` กันไว้ให้แล้ว)
- ข้อมูลทั้งหมดอยู่ในไฟล์เดียวใน Blobs: เหมาะกับหลักพันรายการ ควร Export สำรองเป็นระยะ
- หลัง deploy ครั้งแรก ให้ลองยืม-คืนจากสองเครื่อง และถ้า build สำเร็จแล้วแนะนำให้รัน `npm install` แล้ว commit `package-lock.json` เพื่อล็อกเวอร์ชันของ `@netlify/blobs`
